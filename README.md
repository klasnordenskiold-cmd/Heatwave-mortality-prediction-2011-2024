# Heatwave-mortality-prediction-2011-2024 in RStudio

This repository contains the analytical code used in the study examining predictors of heatwave-related mortality among older adults.

Repository Contents
Primary Analysis

primary_analysis.R

Contains the code used for the main machine-learning analysis reported in the currently unpublished manuscript, including:

Data preprocessing and feature engineering
Model training and validation
Identification and ranking of predictors associated with heatwave-related mortality
Generation of results presented in the primary analyses
Sensitivity Analysis

sensitivity_analysis.R

Contains code used to assess the robustness of the primary findings through alternative analytical choices and model specifications.

Data Availability

The individual-level data used in this study contain sensitive personal information and are not publicly available. Access is subject to ethical approval and applicable data protection regulations.

Users with access to the original data sources may reproduce the analyses by adapting the file paths and input data specifications provided in the scripts.

Reproducibility

The analyses were conducted using the software versions and packages specified within each script. Random seeds were fixed where applicable to facilitate reproducibility.
